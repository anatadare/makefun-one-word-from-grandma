# One Word From Grandma

Entry for the make.fun competition "One Word From Grandma"
(u-0xkianno-one-word-from-grandma-f04bed16).

The program writes a single word to `/output/entry.txt`: the word a
grandma would text about AI. The word is **AyeEye**, how a grandma hears
the initials "A.I." and types them back as one word.

## Run

```sh
python3 main.py
```

It writes `AyeEye` to `/output/entry.txt` (6 bytes, one word, no
whitespace).
